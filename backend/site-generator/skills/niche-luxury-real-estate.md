# Niche Visual Grammar: Luxury Real Estate

Use only for real-estate agencies, architecture-led property businesses or a verified
premium-property context. Aim for calm, architectural confidence and negative space.

- Favor cinematic or architectural-editorial hero compositions, with a discreet
  navigation and a serif/display voice paired with a quiet sans.
- Let a strong property or architecture image carry atmosphere; use broad views,
  material detail and golden-hour light only when supplied or requested as stock.
- Keep calls to action elegant and limited. Do not turn the first fold into a grid of
  property cards.
- Use small, factual metrics only if the source provides them. Never invent listings,
  prices, features, property counts or awards.
- On mobile, preserve the image subject and move text to a reliable contrast surface
  when an overlay crop becomes unsafe.
