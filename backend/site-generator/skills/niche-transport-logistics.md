# Niche Visual Grammar: Transport and Logistics

Use for transport, freight, fleets, delivery operations and logistics.

- Let a vehicle, route, facility or movement-oriented image create a cinematic first
  fold. Strong type and controlled warm signal accents can communicate scale and
  reliability without making the page bureaucratic.
- Use motion blur, night light or route motifs only when the available or requested
  media supports them. Keep the CTA and navigation readable above the scene.
- Data modules must contain verified operational facts; never fabricate coverage,
  fleet size, delivery time, tracking, routes or certifications.
- Recompose the hero for mobile so the vehicle and headline remain visible instead of
  competing for the same crop.
